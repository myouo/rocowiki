先确定宠物用于什么玩法，再看实际配置与材料来源。基础属性、个体培养和对战中产生的状态变化分开记录。

## 先确认培养对象

在 [宠物图鉴](/pets/) 核对编号、形态与技能池。进化关系与皮肤、外观或其他关联形态使用各自的资料类型；没有来源时不自动推断它们共享技能和数据。

## 一套配置包含什么

| 部分 | 记录内容 |
| --- | --- |
| 基础资料 | 属性、种族值、相关形态 |
| 能力培养 | 等级、天赋、努力值、性格及其他适用项目 |
| 技能配置 | 具体技能、获得条件与配置理由 |
| 血脉 | 名称、条件与已核实效果 |
| 装备与其他培养 | 适用对象、效果、获得来源 |
| 使用场景 | 对战规则或具体挑战、承担的任务 |

字段是否适用以实际游戏资料为准；不能因为模板存在该字段就给每只宠物填入同一种内容。

## 培养前先查来源

技能、道具与宠物的获得方式分别记录。确认所需资源当前可获取、是否需要前置条件，以及是否存在历史限定。

## 配置推荐应说明理由

推荐配置应写明目标、必要条件、可替代项和差异，而不只给一组数值。没有验证过的能力阈值不要包装成“必须达到”。

比较配置时使用相同等级和条件；工具尚未具备现行公式时，以其公开假设为准，不把演示值当成游戏计算结果。
