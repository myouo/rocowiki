本目录面向**洛克王国页游**。先区分问题属于哪个系统，再查规则和具体条目；《洛克王国：世界》的能量、精灵和战斗规则不并入本目录。

这是一张资料覆盖地图。列有入口表示已有相应栏目，不表示该系统的全部公式、概率与当前版本行为都已验证。调查日期：2026-10-23。

## 一场战斗怎样发生

阅读顺序：**[战斗机制目录](/mechanics/overview/) → [战斗拆解与算例](/mechanics/battle-walkthrough/) → 对应专题 → 具体技能和宠物。**

| 层次 | 分配给哪个主题 | 主要边界 |
| --- | --- | --- |
| 行动与时间 | 先手、速度、自然回合、技能回合、连续技能 | 谁先动与技能内部怎样结算分别解释 |
| 命中与伤害 | 命中、威力、固伤、暴击、护盾、限伤、治疗 | 技能类别不能代替每一段事件的伤害类型 |
| 状态与资源 | 异常、强化、标记、PP、血脉 | 删除、消耗、净化、免疫和重置分别记录 |
| 战场与退场 | 天气、环境、换宠、驱逐、阵亡、连锁、场下 | 同一效果在不同对象和时点可能有不同结果 |
| 效果相遇 | 覆盖、共存、刷新、到期清理 | 以两个具体来源、有方向的配对为单位查证 |

## 内容如何分配，怎样避免重复

通用规则写在机制专题；宠物与技能条目保留自身条件、公式和例外；赛事页保存场景限制；活动页保存时间与获取条件。同一结论只维护一份主要解释，其他页面链接过去。

例如：普通攻防强化倍率写在[伤害专题](/mechanics/damage/)；【趁势击】因阴雨改变结算次序的规则留在[技能条目](/skills/1961/)并从案例链接过去；不能把它推广为“所有技能都先降防再造成伤害”。
