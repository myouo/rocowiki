一篇可复用的挑战攻略需要说明“在什么条件下，使用什么配置，按什么步骤完成”。先确认对象与规则，再比较自己的配置。

## 确认挑战记录

从 [挑战资料](/challenges/) 查入口、前置条件、参与限制与奖励。活动期间的挑战应关联到对应的 [活动记录](/events/)，避免跨期套用变化过的规则。

## 配置要求分清必要与替代

| 项目 | 应有说明 |
| --- | --- |
| 宠物与形态 | 必须对象与可替换对象 |
| 技能 | 关键技能、获取方式及用途 |
| 培养 | 实测配置，以及哪些数值影响过程 |
| 血脉与装备 | 是否参与关键阶段 |
| 消耗 | 材料、次数或其他成本，附来源 |

[查宠物](/pets/) · [查技能](/skills/) · [查培养资料](./training.md)

## 步骤要能应对变化

攻略按“条件 → 操作 → 预期结果 → 失败时处理”写。只写固定的回合按键顺序，无法解释与实测不一致的情况。

关键步骤附带技能阶段、PP、状态与对手动作。需要概率条件时说明成功条件，尚未统计的成功率不填写百分比。

## 复现与修订

记录挑战版本、测试日期、配置与完整过程。投稿时指出哪一步产生差异，并附对应证据；新结论应保留原攻略的适用范围。
