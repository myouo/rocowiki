先明确目标玩法和已有资源，再决定参加什么活动、培养哪只宠物。不要从一份缺少适用日期的推荐名单直接投入资源。

## 第一步：整理已有宠物

到 [宠物图鉴](/pets/) 查询已有宠物，核对具体形态、技能池、血脉与培养资料。名称相近或存在多个形态时，确认编号与获取关系。

记录需要补充的技能、培养材料和前置条件；已有宠物是否适合当前目标，应结合具体玩法分析。

## 第二步：看当前还能获得什么

打开 [活动查询](/events/)，先看开放时间与参与条件，再看奖励和每天操作。历史活动与本次开放记录分开，避免把过去的获得方式当成当前入口。

| 需要核对 | 作用 |
| --- | --- |
| 开放与结束日期 | 判断现在能否参与 |
| 地点与进入方式 | 找到实际入口 |
| 前置宠物或材料 | 估算准备成本 |
| 每日限制与任务条件 | 安排参与顺序 |
| 奖励与获取次数 | 确认最终获得对象 |

## 第三步：选择近期目标

| 目标 | 推荐查询路径 |
| --- | --- |
| 补充收藏与图鉴 | [宠物](/pets/) → [获取活动](/events/) → [地图](/places/) |
| 完成挑战 | [挑战资料](/challenges/) → [PVE 攻略阅读](./pve.md) |
| 熟悉对战 | [对战资料](/battle/) → [战斗机制](/mechanics/overview/) |
| 补齐培养 | [培养资料](./training.md) → [道具索引](/items/) |

## 使用攻略时保留适用条件

查看攻略的宠物、技能、培养条件与更新时间。配置不完整时先找替代方案，判断差异影响哪一步，再决定是否照做。

本页提供查询顺序；当前原型未维护实时强度排行或现行活动推荐名单。
