同一只宠物身上的异常、能力变化与专属标记使用不同资料类型。清除、免疫、锁定也分别记录，避免将效果统一概括成“净化”。

## 状态分类

| 类型 | 记录重点 |
| --- | --- |
| 异常状态 | 施加、命中条件、作用、解除与免疫 |
| 强化或弱化 | 对应能力、变化量、当前等级与来源 |
| 强化锁定 | 锁定的能力、对象、时长与例外 |
| 专属标记 | 标记来源、所属宠物、层数或计量单位、触发效果 |
| 持续效果 | 起始时机、结算阶段、剩余条件 |

## 清除与免疫

“解除已经存在的效果”和“阻止效果以后施加”回答的是不同问题。条目应分别说明处理对象、触发时点以及排除项。

原文只说明一类效果时，不将它扩写为无条件免疫；遇到“清强”“锁强”等精简词，保留可以展开查看的完整解释。

## 标记必须带来源

标记同名、同图标或视觉相似时，用来源实体和作用对象识别。一个可用于实测的记录至少包含：来源技能或血脉、施加者、承受者、数值、创建阶段与消失条件。

若标记显示数值尚无权威解释，记录观察到的变化，不自行命名单位或上限。

同名效果的来源列表放在 [效果档案](./effects.md)。从 [覆盖、共存与解除](./interactions.md) 或 [效果关系对照](/mechanics/relations/) 查相互关系，并分别核对重复施加、到期和换宠时的处理。

## 换宠时怎么查

分别记录换宠前后仍保留、被清除和发生转移的效果。不能把某个专属技能的测试结果推广为所有状态的统一规则。
