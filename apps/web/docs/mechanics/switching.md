## 换下后什么仍然存在

| 效果挂载位置 | 查询问题 |
| --- | --- |
| 宠物本身 | 层数、持续回合、免疫与标记是否清除？ |
| 队伍一侧 | 换上其他宠物后是否仍受影响？ |
| 整个战场 | 天气、环境、场地限制是否变化？ |
| 下一只上场目标 | 由谁、在什么时候对下一只施加？ |
| 待结算事件 | 触发条件以后满足时是否继续执行？ |

这些挂载位置是资料归类；具体技能可能涉及其中多个位置，需拆成多项效果。

## 下一只与指定宠物不同

“下一只上场”“某个背包位置”“某个编号”和“上次命中的目标”采用不同描述。若反弹、换位或多只同宠会改变目标身份，保留对应例外。

从 [效果档案](./effects.md) 可查看来源与承受者；从 [血脉与被动触发](./passive.md) 可查看上场条件。

## 驱逐失败看原因

驱逐无效时，先区分免疫、没有可替换目标、技能未命中和前置未满足。某个分支要求“免疫驱逐”时，不应自动扩大为所有驱逐失败情况。

## 场下也要记录具体目标

队伍回复、波及、标记等条目展示目标选择规则和范围。涉及最低精力、最高上限、属性或顺位时，将这些限定直接放在作用对象旁边。
