**行动顺序**回答谁先动；**效果顺序**回答一次行动里先发生什么；**冲突关系**回答多个效果相遇时如何处理。三个问题分别查询。

## 自然回合与技能回合

官方论坛版主团[《回合的基本概念》](https://17roco.gamebbs.qq.com/forum.php?mod=viewthread&tid=157475)区分自然回合与技能回合。自然回合围绕双方选择与执行行动推进；多回合技能的后续发动、持续状态的起止，可能采用另一种计数方式。核对日期为 2026-10-23，以下为来源说明，不是本站新增的实测结果。

因此不能看到“持续四回合”，就把所有效果都设为四次自然回合末统一减一。天气、持续攻击、防控要各查自己的计数与带出条件；原帖为教学使用的分类也不代表客户端内部的效果枚举。

【守护之力】的结束时点、多个技能的带出位置，以及中途击败目标是否中断后续发动，会让同一段持续效果在不同场景呈现不同结果。具体算例见[战斗拆解](./battle-walkthrough.md)，阶段记录见[技能阶段](./stages.md)。

## 四种时间范围

| 范围 | 典型问题 |
| --- | --- |
| 对战全局 | 计数是否跨换宠保留，次数上限怎样重置？ |
| 一回合 | 哪些持续效果结算，回合数何时递减？ |
| 一次行动 | 先回复、先清除，还是先施加状态？ |
| 一段事件 | 伤害进入护盾前后、最终掉血后分别触发什么？ |

## 查询一段技能的过程

在技能详情中选择阶段，按“前置条件—本段事件—后续分支”阅读。引用资料只明确其中一部分顺序时，未明确的部分仍标未知，不补成完整服务端执行顺序。

先从 [技能阶段与结算](./stages.md) 定位主动与持续阶段，再从 [效果关系](./interactions.md) 查看相互影响。

## 旧效果到期也可能是关键

查询覆盖关系时，除了刚施加后的结果，还要检查原效果本来的到期时点、新效果到期时点，以及中间换宠后的结果。

一张状态截图只能证明那个时点的表象，不能证明持续时间已经刷新、旧实例已经删除或后续清理互不影响。

## 相同措辞需要相同判据吗

“受到伤害”可能对应伤害事件、最终结算值或行动前后精力变化。具体技能采用什么判据，只在证据明确时填写，不能从近似措辞继承结论。
