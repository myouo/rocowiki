查回复为什么没有达到预期，先固定回复来源和计算基准，再检查减疗、禁疗、转化以及当时的精力状态。

## 回复来源

| 类别 | 需要保留的信息 |
| --- | --- |
| 主动技能回复 | 回复谁、数值基准、与其他技能效果的先后 |
| 血脉或标记回复 | 触发事件、触发次数、是否需要命中 |
| 持续回复 | 起止阶段、换宠后的处理 |
| 场下与队伍回复 | 目标选择规则、存活要求、队伍顺位 |
| 转化得到的回复 | 原始事件、转化比例、限制与例外 |

## 减疗、禁疗和转化分别查

**减疗**查剩余回复如何计算；**禁疗**查哪些回复来源受到限制；**转化**查输入事件如何被改写。三者同时存在时，查询具体配对与时机，不能将它们合成一个“不能回血”的状态。

同样，保留精力、复活与精力上限变化应在自己的效果档案中说明，不从表面数值推断它一定属于常规治疗。

## 条件变化时怎样判断

| 变化 | 要核对的条件 |
| --- | --- |
| 换宠后仍有回复或限制 | 效果挂在宠物、队伍还是某个待结算事件上 |
| 被反弹后触发 | 当前作用对象与触发动作归属 |
| 护盾吸收后仍回复 | 条件检查伤害事件、最终伤害还是精力差 |
| 原限制到期后异常 | 旧效果的清理是否影响后施加效果 |
