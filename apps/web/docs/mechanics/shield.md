受伤结果偏离预期时，先确认伤害类型与保护效果。护盾、减伤、免伤和伤害上限使用不同字段，不能仅靠最终掉血量判断效果来源。

## 四类信息分开看

| 信息 | 需要查明什么 |
| --- | --- |
| 护盾 | 生成条件、盾量、吸收对象、消耗与清除 |
| 减伤 | 适用伤害、比例或数值、条件与持续时间 |
| 免伤 | 触发条件、伤害范围与例外 |
| 伤害上限 | 针对一次结算、一段还是其他范围 |

## 先区分伤害来源

记录攻击技能的完整原文，并区分普通威力伤害、固定数值、比例描述与多次结算。百分比的基准写明是最大精力、当前精力还是其他值。

若同一技能含多种伤害，逐项记录，不将总掉血量当作单一公式的结果。

## 怎样验证结算顺序

使用同一目标与同一条件，先记录没有目标保护效果时的结果，再记录存在效果时的结果。每次只改变需要验证的条件，并记录盾量和精力各自变化。

单次观察只能说明这一组条件下的结果。现行公式、取整位置、随机分布及所有例外尚未核验时，计算工具应明确展示假设与适用范围。

两个来源都写“护盾”或“减伤”时，从 [效果档案](./effects.md) 识别具体来源，再查 [效果关系对照](/mechanics/relations/)。不同保护机制的结算先后与同名效果的覆盖关系分别记录。
