查“必中为什么没有生效”时，先定位是哪一部分效果未发生：技能未命中、伤害被保护效果处理、附加状态被免疫，是不同现象。

## 一次技能分开检查

| 检查项 | 要回答的问题 |
| --- | --- |
| 必中条件 | 是否要求某种天气、出手顺序或已受到伤害？ |
| 适用范围 | 对整个技能、某段伤害，还是某个附加效果有效？ |
| 对方效果 | 是否存在必闪、致盲、反弹或作用对象变化？ |
| 附加状态 | 技能命中后，状态是否另有免疫或触发条件？ |
| 实际结果 | 显示未命中，还是出现命中动画但没有掉血或状态？ |

## 命中与回避的等级

命中和回避图标识别对应的等级修正，不能代替本次技能的实际命中结果。记录修正等级后，还需核对技能的必中条件、对方的闪避效果及当前作用范围；不套用物攻或物防的强化倍率来推算命中概率。

## 条件写在必中旁边

技能表中的“必中”保留可展开的条件。分支改变命中方式时，分别在对应分支展示；未说明的分支不自动继承。

诸如“受到先手伤害”的条件，还需查看 [结算时点](./timing.md)：一次伤害事件和行动前后精力减少未必是同一个判断对象。

## 必中与必闪相遇

从 [效果关系对照](/mechanics/relations/) 选择两个**来源明确**的效果，查看该配对的施加顺序、条件和证据。未收录具体关系时显示待核验，不用关键词的字面强弱替代结论。

需要提交实测时，记录双方技能、相关标记、出手顺序和每段结果。只有最终掉血截图通常不足以区分命中问题与伤害被免除。
