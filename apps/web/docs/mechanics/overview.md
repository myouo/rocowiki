## 第一次阅读的顺序

先读[战斗拆解与算例](./battle-walkthrough.md)，再沿下方目录进入专题：**面板与属性 → 行动排序 → 命中与逐段伤害 → 持续回合 → PP、状态与战场 → 换宠与效果交互**。想查培养、捕捉、遗传、活动和探索的归属，进入[游戏系统与机制目录](/guides/game-systems/)。

案例中的自拟数值用于解释规则，不冒充实战；来源记载、历史实测和当前复核分别保存。核心原始教程、版本范围与待调查项目见各专题的来源说明。

## 资料有分歧时

相互关系以**具体来源、方向、条件、时机和版本**为单位保存。空白表示未收录；待复核表示已有历史线索；有争议表示存在不能同时成立的证据。它们都不等于“没有效果”。

从 [机制实测与争议记录](./evidence.md) 查看证据要求。每页右下角的反馈入口可以提交错误位置与复现信息；准备直接修订正文时，先看 [贡献指南](/help/contributing/)。
