看到相同名称或图标时，先选择**来源技能或血脉**。同名效果只是检索入口；是否共享行为、能否互相覆盖，需要单独的证据。

[打开效果关系对照](/mechanics/relations/) · [查看压迫（双损）档案](./effects/pressure.md)

## 一个效果先回答六件事

| 信息 | 玩家要查的内容 |
| --- | --- |
| 来源 | 哪只宠物、哪个技能或血脉、具体哪一段 |
| 对象 | 当前宠物、场下宠物、下一只上场、队伍或战场 |
| 作用 | 修改什么，数值基准和适用范围是什么 |
| 时机 | 何时施加、何时触发、何时结束 |
| 重复施加 | 叠层、刷新、替换、共存或失败的已知条件 |
| 相互关系 | 谁能影响它，影响发生在施加还是清理阶段 |

## 相同显示名不直接合并

例如查询“压迫”时，先显示来源列表，再选择具体效果对照。一个技能含有多个状态时，也应分别选择；技能名称本身不是效果的唯一身份。

站内资料标识用于稳定引用。除非已有来源确认，页面不把自建标识称为游戏服务端效果编号。

## 关系标签怎样理解

| 标签 | 能说明什么 |
| --- | --- |
| 覆盖 | 新效果替换已有效果，需写明方向和条件 |
| 共存 | 指定条件下两者分别存在或分别结算 |
| 刷新 | 同一效果的持续时间或数值被更新 |
| 叠层 | 增加层数或独立实例，需注明上限 |
| 互相解除 | 某方的清理会影响另一方，不等同于施加时覆盖 |
| 未知 | 当前证据不足，不能推导为没有相互作用 |

## 从效果回到宠物

效果页同时连接来源技能、来源宠物、所属机制和证据。宠物页只展示与该宠物有关的效果及冲突提示，完整的交互关系由这里维护，避免多处说明各自失效。
