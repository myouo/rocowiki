查“技能为什么不能用”时，分别看当前 PP、使用条件与封锁效果。技能的基础 PP 是资料字段；当前 PP 属于具体对局状态。

## 先分清对象

| 描述对象 | 记录要求 |
| --- | --- |
| 单个技能 | 明确技能、选取规则及是否有例外 |
| 一只宠物的多个技能 | 明确范围，不能只写“群删” |
| 多只宠物 | 明确场上、场下、全队或指定目标 |
| 使用者与对手 | 直接写明双方归属，避免“本方”随叙述变化 |

## 删除、消耗与回复

将一次行动的变化拆成“使用前 → 使用或额外消耗 → 技能效果 → 后续阶段”。每个变化保留来源、数值、目标选择条件与发生时机。

官方论坛版主团[技能基础教程](https://17roco.gamebbs.qq.com/forum.php?mod=viewthread&tid=157477)及[回合教程](https://17roco.gamebbs.qq.com/forum.php?mod=viewthread&tid=157475)把点选消耗与实际发动分开：点选技能会消耗 PP，未能成功释放并不自动返还。核对日期为 2026-10-23，属于来源记载；异常扣除仍需完整对局条件复核。

例如，起始 4 PP 的技能在普通点选后记为 3；若另有已确认的额外消耗 1 PP，则记为 2。这个合成记账例子没有假定任意一种压迫都固定消耗 1，也没有把后续的删除、吸取和回复算在同一步。

| 字段 | 示例写法，非具体技能效果 |
| --- | --- |
| 来源 | 某技能 / 某血脉 / 持续效果 |
| 方向 | 消耗、删除或回复 |
| 对象 | 当前技能 / 指定技能 / 满足条件的技能 |
| 选取依据 | 本回合、上回合、最近一次等原文限定 |
| 时机 | 释放前、指定阶段、回合结束等 |

“本回合”“上回合”“最近一次”属于不同条件，不能互换或在精简时删掉。

## 技能无法使用的记录

先记录界面呈现的现象，再写判断。PP 为零、技能被限制、未达到技能条件，应使用不同状态，不把它们合并成“不可用”。

遇到异常情况，补充限制来源、开始回合、持续条件与解除方式；不能确定时只记录观察结果。

## 相同双损为什么不同

从 [压迫（双损）](./effects/pressure.md) 选择来源，再进入 [效果关系对照](/mechanics/relations/)。额外消耗、技能直接删除和旧效果的解除分别查看；“免疫删除”这个标签本身不能回答所有 PP 变化的原因。

对照结果同时记录施加后和旧效果到期后的状态。只有当前 PP 数值相同，不能证明两种来源共存或互相覆盖。
