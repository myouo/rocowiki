宠物图鉴的六维图用于比较**种族值分布**。实际对局的能力、当前强化和技能临时加成需要另外核对，不能直接把图鉴六维当作伤害计算输入。

## 查面板时看什么

| 信息 | 查看位置 | 用途 |
| --- | --- | --- |
| 种族值 | [宠物图鉴](/pets/) | 比较基础分布，识别培养方向 |
| 等级与培养结果 | 对局宠物面板 | 固定本次计算输入 |
| 强化与弱化 | 战斗状态、技能说明 | 记录本回合的可见能力变化 |
| 临时能力视作值与加成 | 技能、血脉详情 | 保留触发条件和适用的一次行动 |
| 属性与属性变更 | 宠物、技能、战场条目 | 核对当前实际参与判断的属性 |

## 属性关系必须带场景

查克制关系时，同时记录技能属性、承受者当前属性与战场效果。若技能提到改变属性、无视抵抗或改变克制关系，应从对应效果进入，不能把这种例外改写进基础属性表。

本版尚未收录经过独立核验的完整现行属性矩阵，因此不从其他作品的属性表补齐空白。

官方论坛版主团[《属性克制抵抗关系表》](https://17roco.gamebbs.qq.com/forum.php?mod=viewthread&tid=158387)正文于 2026-10-23 重新核对，记载的基础组合如下。这里引用组合规则，不等于本站已逐格导入、实测完整属性矩阵。

| 技能对承受方两个属性的关系 | 该来源的普通组合结果 |
| --- | --- |
| 两者都克制 | 双重克制，×3 |
| 两者都抵抗 | 强力抵抗，×1/3 |
| 一克制、一抵抗 | 不克制不抵抗，×1 |
| 一方普通，另一方克制或抵抗 | 保留另一方的 ×2 或 ×1/2 |
| 两者都普通 | ×1 |

原帖另列神属性技能的例外：不能因为目标有两个常规属性，就按双重克制 ×3 计算。属性被改变、被视作另一属性，或技能改写抵抗关系时，仍需具体来源。不要套用其他作品常见的 ×4、×1/4 或本系加成。

## 能力与强化等级

`+2 物攻` 表示物攻的强化等级为 +2；`-1 速度` 表示速度的强化等级为 -1。数字记录的是等级，图标识别对应能力。强化等级与能力数值分开记录，不将等级直接加到面板数值上。

### 物攻

物理攻击能力。物理威力伤害通常配对攻击方的物攻与承受方的物防；物攻强化表示对这项能力的等级修正。

### 物防

物理防御能力。物防强化与物防能力值分别记录，技能明确要求忽略、重置或替代时按对应技能规则核对。

### 魔攻

魔法攻击能力。魔法威力伤害通常配对魔攻与魔防。

### 魔防与魔抗

同一防御能力在不同界面中的名称。其强化等级与当前能力值分别记录。

### 速度

速度能力参与行动顺序和部分技能的比较或计算。速度强化与技能先手值分别记录，参见[速度与先手](./priority.md)。

普通攻防计算的强化倍率和取整方式见[伤害类型与计算条件](./damage.md)及[伤害计算器](/tools/damage/)。命中、回避等等级修正另见[命中与闪避](./accuracy.md#命中与回避的等级)，不能直接套用攻防倍率。

## 强化不等于所有加成

“提升能力等级”“视为某等级”“直接改变能力”和“增加技能威力”采用不同标签。阅读伤害说明时，先确定它修改的是哪一个量，再查看该量能否被清除、反转、锁定或继承。
