宠物图鉴的六维图用于比较**种族值分布**。实际对局的能力、当前强化和技能临时加成需要另外核对，不能直接把图鉴六维当作伤害计算输入。

## 查面板时看什么

| 信息 | 查看位置 | 用途 |
| --- | --- | --- |
| 种族值 | [宠物图鉴](/pets/) | 比较基础分布，识别培养方向 |
| 等级与培养结果 | 对局宠物面板 | 固定本次计算输入 |
| 强化与弱化 | 战斗状态、技能说明 | 记录本回合的可见能力变化 |
| 临时能力视作值与加成 | 技能、血脉详情 | 保留触发条件和适用的一次行动 |
| 属性与属性变更 | 宠物、技能、战场条目 | 核对当前实际参与判断的属性 |

## 属性关系必须带场景

查克制关系时，同时记录技能属性、承受者当前属性与战场效果。若技能提到改变属性、无视抵抗或改变克制关系，应从对应效果进入，不能把这种例外改写进基础属性表。

本版尚未收录经过独立核验的完整现行属性矩阵，因此不从其他作品的属性表补齐空白。

## 强化不等于所有加成

“提升能力等级”“视为某等级”“直接改变能力”和“增加技能威力”采用不同标签。阅读伤害说明时，先确定它修改的是哪一个量，再查看该量能否被清除、反转、锁定或继承。
