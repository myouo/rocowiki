查被动效果时，先确认来源和触发事件。血脉、技能携带效果、上场触发与持续标记分别显示来源，避免误以为都需要主动使用技能。

## 什么时候触发

| 事件入口 | 查看什么 |
| --- | --- |
| 进入对战或上场 | 首发与非首发、携带技能、PP 或队伍要求 |
| 主动使用技能 | 技能类别、命中要求、次数与目标身份 |
| 造成或受到伤害 | 每段还是每次行动、伤害判断的具体时点 |
| 获得或失去状态 | 变化前后的数量、阈值与例外 |
| 回合内固定时点 | 触发阶段、持续条件、结束处理 |
| 换下或阵亡 | 是否清空、转移或保留待结算效果 |

## 专属资源放在血脉旁边

资源名称、当前量、上限、获得和消耗来源集中展示。点击相关技能时，只强调它如何改变该资源，完整规则回到对应血脉条目查阅。

未核验的资源单位或上限显示待核验。单凭数值或图标相似，不将两只宠物的专属资源合并。

## 同一个条件怎样避免读错

保持条件的从属关系，例如携带技能条件、PP 阈值和上场条件应处在同一分支。技能主动效果与携带期间效果分别列出起止时间。

## 与其他效果一起查

血脉触发的效果也进入 [效果关系对照](/mechanics/relations/)。结果需要说明对照的是哪一个被动分支，以及施加、结算和清理分别发生在何时。
