读复杂技能时，同时保留**条件、作用对象与阶段**。第一段、中间段、末段，单次动作的伤害次数，以及回合内时点属于不同信息，不能相互代替。

## 三种顺序

| 顺序 | 问的是什么 |
| --- | --- |
| 技能阶段 | 当前属于该技能描述中的哪一阶段 |
| 伤害次数 | 本次动作第几次造成或结算伤害 |
| 回合时点 | 本回合何时施加、消耗、清除或结算 |

具体技能有几段、如何推进、是否重置，由它的来源与实测记录决定。资料模板不会强制所有技能拥有相同阶段。

主动再用一次、原技能持续带出和旧效果到期清理分别保留记录；它们之间的关联可继续查 [触发顺序与结算时点](./timing.md) 与 [覆盖、共存与解除](./interactions.md)。

## 条件必须与分支一起阅读

精简说明可以缩短文字，但不能把一个共同前提拆散后，让各分支看起来无条件生效。

| 层级 | 示例结构，非某个真实技能 |
| --- | --- |
| 时机 | 在指定伤害结算前 |
| 共同动作 | 按条件处理自身某项状态 |
| 分支 A | 满足条件 A 时，采用结果 A |
| 分支 B | 满足条件 B 时，采用结果 B |
| 后续 | 继续执行该阶段剩余效果 |

共同动作与分支保留从属关系；“至少”“最多”“本回合”“上回合”等限定词不能因压缩版面而删除。

## 原文、解析与实测

| 内容 | 展示方法 |
| --- | --- |
| 技能原文 | 原样引用并标注出处与获取日期 |
| 条件化解析 | 按阶段组织，保留对象与分支 |
| 已验证结论 | 附复现条件及证据 |
| 待核问题 | 单独列出，不混入确定语句 |

解析与原文有冲突时，应允许读者直接对照，并从对应段落提交修订。
