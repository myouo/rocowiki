先查“这一段伤害从哪里来”，再查它受到哪些效果影响。一个技能可以包含多项伤害与治疗，最终精力变化不能代替每项结算记录。

## 伤害按来源查

| 查询类别       | 阅读重点                                   |
| -------------- | ------------------------------------------ |
| 威力伤害       | 技能威力、物理或魔法类别、属性及临时修正   |
| 固定或比例描述 | 数值基准、上下限和取整位置                 |
| 附加伤害       | 触发条件、来源技能或血脉、发生时点         |
| 反伤与反弹     | 反回的对象、内容与时机，是否改变技能作用者 |
| 波及           | 场下目标选择、伤害范围及能否致死的具体条目 |
| 自损与代价     | 何时支付、触发失败时是否仍支付             |

这些是资料的查询类别，并非对所有技能适用的伤害公式。

## 同一技能逐段阅读

每段分别展示对象、类型、基准和命中要求。造成伤害前后的回复、状态清除、标记施加与 PP 变化，在 [技能阶段](./stages.md) 中保留原有顺序。

“最大精力”“当前精力”“已损精力”直接显示在数值旁边；伤害上限和最低值也与对应伤害项放在一起。

## 多种保护效果同时存在

从 [护盾与减伤](./shield.md) 查每种保护作用于什么，再进入 [覆盖与共存](./interactions.md) 查它与其他效果的关系。比较的对象可能是两个持续效果，也可能是伤害转换与保护效果之间的结算顺序。

在没有完整证据时，不把护盾、限伤、转化、反伤排列成一条通用顺序。

## 计算工具的适用边界

[伤害计算器](/tools/damage/) 已支持普通物理、魔法威力攻击的参考计算。输入的是本次攻击的实际攻防能力与已知威力；物理配对物攻与物防，魔法配对魔攻与魔抗。普通、单重抵抗和单重克制分别计算，不能把双属性关系直接乘起来。

目前的计算范围是跨系、非暴击、没有其他伤害修正的单段威力攻击。本系加成、天气环境、血脉、护盾、限伤、锁血、伤害转化、条件威力、固伤、多段与波及，需要对应技能和效果的专用规则；选择这些条件时，工具会停止输出，说明缺少什么依据。

## 普通威力的参考模型

2010 年的页游攻略给出以等级、威力、攻防比和克制关系构成的基础表达式。这里将它改写为代数上相同的形式：

```text
B = (攻击方等级 + 5) × 威力 × 实际攻击 / (125 × 实际防御) + 2
本工具参考值 = floor(B × 克制修正 × r)
```

`floor` 表示向下取整。工具将整个分式合成后再取整，这是一项**明确的计算约定**。原始基础教程没有写出客户端中间取整顺序，因此这里不把这个约定写成已证实的游戏底层实现。[基础表达式来源](https://news.4399.com/luoke/miji/201008-25-76090.html)；[单重相克修正来源](https://news.4399.com/luoke/miji/201102-28-87952.html)。

例如，在 100 级、100 威力、实际攻击 300、实际防御 300、普通克制关系下，`B = 86`。按下述 21 档，工具输出 68–86；这是参考模型的回归例子，不是本站已经完成的游戏实测。

## 随机浮动与证据状态

超级楚的無頭于 2022-06-14 发布的[原始实测视频《揭开伤害浮动机制的真面目》](https://www.bilibili.com/video/BV1dY4y1W7om/)在约 04:00 展示了 21 个伤害值的频数表，约 04:30 展示了逐档系数与结果。工具据此采用：

```text
r = 0.80、0.81、0.82、……、0.99、1.00
```

这些档位固定枚举，不允许任意输入浮动上下限。不同系数取整后可能产生相同整数。历史实验中的频数检验不等同于当前客户端的精确概率证明，因此工具不提供击杀概率或“必定击杀”的判断。

视频片头的取整括号按字面执行会出现矛盾，不能据此确认中间取整；本站只引用后半部分能够直接查验的随机档位数据。当前游戏版本是否还有取整或特殊伤害差异，仍需按 [实测规范](./evidence.md) 记录双方配置、完整伤害样本与版本后复核。

## 从培养得到实际能力

[能力计算器](/tools/stats/) 使用官方论坛版主团[《PK入门·1》宠物能力培养指南](https://17roco.gamebbs.qq.com/forum.php?mod=viewthread&tid=162202)末楼的六维公式图（公式段编辑于 2026-04-14），并将面板与守护兽的战斗加成分开展示。

```text
E = floor(努力值 / 4)
B = floor((2 × 种族值 + 天赋 + E + 亲密值) × 等级 / 100)
精力 = B + 等级 + 10 + 装备 + 守护兽
非精力 = floor((B + 5) × 性格修正) + 装备 + 守护兽
```

这里的亲密值包括已分配点数和关系的额外加成；速度的亲密、装备与守护兽项均为 0。性格使用精确的 `9/10、1、11/10` 比值计算，避免十进制乘法误差改变向下取整结果。能力计算所得是尚未叠加战斗中强化、血脉和临时效果的基础值；带入伤害工具后，要按当次出手条件继续核对。
