查“谁能盖掉谁”，在 [效果关系对照](/mechanics/relations/) 左侧选**已有的效果**，右侧选**准备施加的效果**。两个选择都包含来源，不只比较状态名称。

## 先看结论适用于哪里

一条结论同时列出承受者、施加顺序、触发阶段、前置条件和证据日期。有明确结论时直接展示“保留谁、移除谁、何时变化”；条件不全时显示缺失项。

**施加 A 后再施加 B** 与 **施加 B 后再施加 A** 分别保存。交换选择后查询另一条记录，不自动将答案对调。

## 施加与清理分开看

| 时间点 | 需要回答的问题 |
| --- | --- |
| 新效果刚施加 | 成功、失败、覆盖、刷新还是共存？ |
| 下一次相关事件 | 哪个效果实际参与计算或扣除？ |
| 原效果到期 | 是否影响后来施加的效果？ |
| 换宠或清除 | 移除哪些效果，是否保留计数或待结算事件？ |

因此，“优先级较高”“共用图标”和“互相解除”不能互相替代。它们描述的是不同的事实。

## 优先关系只用于已证实的范围

一对效果的优先关系不自动推广到所有同类效果。即便分别查到 A 与 B、B 与 C 的关系，也仍需单独确认 A 与 C 的条件与结算阶段。

对照器保留来源报告的关系描述；来源未给出施加结果或完整顺序时，不生成一个看似确定的数值排名。

## 历史实测与现行结论

[压迫（双损）](./effects/pressure.md) 已有历史实测线索，可以用来提出明确的复核问题。本版没有将它们标为当前版本已复测。

新增证据应保留来源日期与测试日期。若不同版本结果不一致，各自保留适用范围，并从当前结论链接到历史记录。

## 未收录的配对怎样补充

对照器空结果保留当前选项，并可从反馈入口提交问题。提交内容应包含两个效果的来源、先后施加顺序、战场条件和关键结果；录像或日志附上对应回合位置。
