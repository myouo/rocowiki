# 参与共建

阅读 Wiki 无需登录。登录后可保存个人草稿、提交文章修改或更新已有宠物与技能资料。

## 投稿流程

1. 打开共建工作台，选择页面，加载当前编辑基线。
2. 编辑正文并添加来源，使用预览检查格式。
3. 保存草稿或提交审核。每次投稿都会锁定独立的内容快照。
4. 审核通过后生成 GitHub 内容提交与 PR，由维护者合并。
5. 站点完成部署并核验版本后，投稿状态变为已发布。

如果基线发生变化，保留原投稿并转入冲突复核。加载新的基线，整理修改，再提交新的候选版本。

## 可选 GitHub 关联

GitHub 绑定不影响站内投稿。只有主动授权公开 GitHub 已验证的提交邮箱时，贡献才会添加 Co-author 标记。公开 Git 历史中的邮箱无法保证撤回。

## 内容格式

支持标题、列表、表格、代码块和安全链接。禁止原始 HTML、可执行 MDX、脚本和任意文件路径。图片仅支持 HTTPS 的 PNG、JPEG、GIF、WebP，来源仍需核实。
