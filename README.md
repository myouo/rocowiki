<a id="about"></a>
## 关于 RocoWiki

RocoWiki 是面向《洛克王国》页游玩家的社区百科，整理宠物、技能、战斗机制与冒险资料，帮助大家查资料、理解规则、分享经验。本站由玩家建设，与游戏官方没有隶属关系。

网站地址：[wiki.rocoai.app](https://wiki.rocoai.app)。阅读站已上线，注册、登录和正式投稿尚未开放。部分资料仍是待完善的样本，以页面标注的来源和适用版本为准。

<a id="reading"></a>
## 查找资料

- **宠物图鉴**：查看属性、技能、培养资料和获取方式。
- **技能与战斗机制**：查阅技能效果、血脉、属性关系与机制说明。
- **活动与冒险**：了解活动记录、地图、人物和任务。
- **PVP 与 PVE**：参考对位分析、挑战方案与攻略。
- **工具与搜索**：使用计算器，按名称或关键词查找词条。

阅读时请留意资料的来源、更新时间与验证状态。实测和推断会随游戏更新而变化；发现过时或有误的内容，欢迎提供证据帮助修正。

<a id="contributing"></a>
## 一起完善百科

可以通过 [资料纠错与建议](https://github.com/myouo/rocowiki/issues/new/choose) 提交问题，附上词条位置、修改理由及可核验来源。引用他人资料时保留出处，不提交账号密码或其他私人信息。

正式投稿开放后，需要注册并登录账号；GitHub 绑定为可选项。修改经过审核后发布。当前界面中的本机积分、点赞与演示操作只保存在本地，不代表公开社区记录。资料及代码贡献的详细要求见 [贡献指南](CONTRIBUTING.md)。
