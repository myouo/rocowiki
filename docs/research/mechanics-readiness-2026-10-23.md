调查日期：2026-10-23。对象：洛克王国页游及当前仓库。基线提交：`a5f81b8cb180798a7941f14c983f0e0886a97c46`。

本轮审查集中于机制资料能否继续编写、阅读、校验和接受修订。结论是：**可以立即沿现有文档与仓库 PR 开展系统研究；尚不能把所有机制页都称为已经开放正式站内投稿，也不能声称已经实测全部游戏机制。**

## 现有框架可以承载什么

| 能力 | 现状与适用范围 |
| --- | --- |
| 文章组织与阅读 | 原生 Markdown 文档、侧栏、章节锚点、静态 HTML 和搜索可以支撑长篇机制说明 |
| 可追溯基础字段 | 官方宠物、技能、天梯快照已有采集日期、配置版本、哈希及数值 ID；基础字段与玩家推导可分开 |
| 规则与案例分层 | 已有基础机制、效果身份、有方向的交互关系和证据状态；可在此基础上逐步补正文 |
| 内容校验 | 既有仓库、架构、类型、测试、链接和完整页面构建可复用；算例仍需额外核算 |
| 受控正式投稿 | 当前只覆盖登记的两篇文章，不自动覆盖 `apps/web/docs/mechanics/`；新增登记还涉及单一内容源、路由、基线、双审和发布候选约束 |
| 实证研究 | 可以写下实验条件与证据，但当前来源登记不代替原始录像或样本，也未提供自动完成游戏测试的能力 |
| 战斗预测 | 现有工具是有边界的参考计算；尚无覆盖全技能、连锁、护盾和事件顺序的完整战斗模拟器 |

因此本轮无需先换框架、拆数据库或制作模拟器。先完成来源调查、目录归属和可靠的说明；正式站内共建的扩展另立实现任务，保留现有服务端权限与审核约束。

## 调查方法与来源边界

从官方论坛现存 Archiver 索引追溯原始帖子，而非把搜索摘要作为正文证据。论坛打印页用于读取跨楼层正文，公开工具另核对 Archiver 内的函数文本；三个六维公式图已单独下载查看。

本轮取得并登记了 **17 篇论坛原帖及 1 份官方公开配置**，详见[来源台账](./mechanics-sources-2026-10-23.json)。台账区分完整相关段落、引言与目录的读取范围；遗传矩阵、抓宠地点、全部血脉与所有图片并未逐项复测或导入。

官方公开配置于 `2026-10-23T15:04:34.091Z` 解析，包 SHA-256 为 `d25931420b280a9a810a4c164d9053dfcc8ff4d90f09443c768f6077d119393d`，与仓库快照相同。技能配置 `B2070`、宠物配置 `B6041`；所查案例技能未发现字段变化。此结论仅证明这份资源快照的一致性，不证明服务端机制没有变化。

公开包含 26 组资源。除宠物与技能外，可见守护兽、装备、场景、任务、农场种子、家具、魔法、小游戏等资源线索。资源存在不等于玩法今天一定开放，配置计数也不作为现存玩法数量。

排除或降级的材料：

- 《洛克王国：世界》资料及其能量制规则：产品不符。
- 把双重克制写成 ×4、强力抵抗写成 ×1/4，或直接套用其他作品公式的页面：不能覆盖已定位的本作原始资料。
- 7k7k《PK的基本概念》：正文声明源自官方论坛，作为追溯线索；本轮找到现存原帖后优先使用原帖。
- 既有 2022 年伤害浮动视频：保留历史引用，不冒充本次新完成的视频实测或当前等概率证明。
- 动态页面抽取后的空表、隐藏字段和图片链接：缺少内容时保持缺口，不补为零或推断不存在。

## 全系统覆盖盘点与目录分工

这一表完成的是首轮系统覆盖盘点，不是对每条技能、掉落概率及历史版本的全量验证。公开阅读入口为[游戏系统与机制目录](../../apps/web/docs/guides/game-systems.md)。

| 系统 | 现有材料与归属 | 下一步调查对象 |
| --- | --- | --- |
| 宠物身份、形态、属性、组别 | 官方配置及宠物图鉴 | 同名变体、不可入图鉴的 Boss 与形态映射 |
| 捕捉与遇敌 | 捕捉原帖、配置字段、场景获取记录 | 出现条件、等级限制、球与状态效果；捕获率字段不是成功率公式 |
| 活动、兑换、限定获取 | 活动时间线、获取记录、每期原公告 | 宠物与资格区别、复刻、过期条件、次数限制 |
| 自然进化、超进化、重生 | 培养指南、重生原帖、进化记录 | 保留项和重置项，遗传/技能石是否丢失，条件与材料 |
| 生蛋与遗传 | 生蛋原帖、组别与技能学习关系 | 亲本携带、可遗传范围、遗传与常规技能的不同；图表待逐项核对 |
| 经验、等级、天赋、性格、努力 | 培养原帖与能力工具 | 中间取整、低等级样本、努力阈值与合法分配 |
| 亲密关系与乐园 | 培养原帖、乐园原帖 | 亲密值与关系加成分离、互动条件、召唤和探险范围 |
| 装备与守护兽 | 公开配置、培养原帖、工具映射 | 面板与战斗加成、穿戴条件、速度例外、特定赛制禁用 |
| 技能、血脉与被动 | 官方技能快照、血脉索引、原始解析 | 携带与被动区别、目标与类别、觉醒条件、专属计数 |
| 战斗基础与逐段结算 | 现有六组机制目录、回合/技能原帖 | 见下方专题与实验矩阵；优先打通学习路线 |
| PVP 规则与阵容 | 赛制原帖、天梯公开配置、对战栏目 | 赛制固有规则与本期禁赛分离；不写死长期“当前最强” |
| PVE、Boss 与挑战 | PVE 与挑战条目、技能原帖的 Boss 例外 | 同名不同效、阶段、免疫、AI、场景伤害与奖励次数 |
| 地图、NPC、任务、徽章与职业 | 场景/任务配置与冒险栏目 | 前置链、实际入口、功能性魔法与任务条件；未开启分支标未知 |
| 道具、货币与资源循环 | 道具栏目、洛克钻与采集原帖 | 来源、用途、上限、刷新、兑换；随机掉落不凭展示值推概率 |
| 农场、家园与生活玩法 | 种子/家具配置、乐园与培养来源 | 种植、锻炼、互动、时间推进与实际生效的玩法 |
| 收集、装扮、成就与小游戏 | 成就/装扮/小游戏资源、原帖索引 | 收集条件、奖励门槛、展示与战斗加成区别 |
| 时段、VIP、周期与概率 | 对应系统的当期公告与原始记录 | 日期、账号条件、冷却/刷新、完整概率样本及不确定性 |

不是每一行都需要立刻新建顶级栏目。一般规则归专题，实体例外归宠物/技能，场景规则归赛事或挑战，日期与获得条件归活动和获取记录，以链接串联。

数值例子采用匿名双方和明确输入，不虚构宠物配招、游戏录像或胜率；案例引用的技能编号已对照本轮官方配置。所有“预期结果”均指来源规则或指定模型，不自动升级为当前实测。

## 本轮验证

数值算例已直接代入现行 `calculatePowerDamage` 核对；官方配置包及案例字段已重新取得比对。实际执行结果：

- 仓库规范、214 个模块的架构边界、内容与类型检查通过；413 项单元测试、225 项生命周期检查（98 次路由转换）、72 项工作台交互检查通过。
- `npm run api:dry-run` 通过。完整检查的首次静态构建中途收到终止信号，未把该命令报告为全程成功；最终单独重跑 `npm run build`，生成 7,482 个完整静态页面，索引 7,469 个页面，无构建错误或断链警告。
- 通过正常构建脚本重新生成 27 篇原生文档及小节基线，并核对新增文档的源正文与打包正文完全一致。
- 使用独立本地 Chrome 读取真实构建结果，检查 1440 × 1000 与 390 × 844 视口；两篇新文档、伤害模型和机制首页入口正常显示。页面无整体横向溢出；手机宽表及公式可在自身区域横向滚动，已检查表格最右列。
- 本轮未执行游戏客户端实测；测试工具、合成数值与本地网页截图均不提升为当前游戏已复核，也不代表本批文章已经部署。
