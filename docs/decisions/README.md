# 架构决策记录 / Architecture decision records

长期影响身份、数据权威、发布协议、许可或兼容性的决策在此追加编号文件。每条记录包括状态（拟议/采纳/被替代）、背景、决策、后果、验证和中英文摘要；变更记录可引用 PR，但不得含凭据或私人报告详情。已采纳记录不抹去历史，后续决策明确指出被替代的条目。

Add numbered records for decisions with lasting effects on identity, data authority, publishing, licensing or compatibility. Each contains status (proposed/accepted/superseded), context, decision, consequences, verification and Chinese/English summaries. Link PRs without credentials or private-report details. Preserve accepted history and explicitly identify superseded records.
